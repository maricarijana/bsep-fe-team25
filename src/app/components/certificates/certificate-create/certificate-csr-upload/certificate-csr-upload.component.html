📝 Certificate Signing Request (CSR)

For End Entity certificates, you need to upload a CSR file that you generated locally. This ensures your private key never leaves your machine.

How to generate a CSR:
  1. Generate a private key: openssl genrsa -out private.key 2048
  2. Create a CSR: openssl req -new -key private.key -out request.csr
  3. Upload the request.csr file below

⚠️ Important: Keep your private.key safe! Never share it.
